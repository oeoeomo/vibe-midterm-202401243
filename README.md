# 모로우 커피 주문·관리 웹앱

카페 음료를 주문하고 관리자 화면에서 주문 상태와 재고를 관리하는 정적 웹앱입니다. HTML, CSS, Vanilla JavaScript로 구현했으며 별도 백엔드나 데이터베이스 없이 동작합니다.

## 개발 목적

고객 주문부터 재고 반영, 관리자 주문 관리까지의 기본 흐름을 한 페이지에서 확인할 수 있는 과제용 웹앱을 만드는 것이 목적입니다. 주문과 재고 데이터를 브라우저 `localStorage`에 보관하므로 서버 없이 동작하지만, 저장 데이터는 사용 중인 브라우저에 한정됩니다.

## 주요 기능

- 아메리카노, 카페라떼, 바닐라라떼, 카라멜마끼아또, 초콜릿라떼 메뉴와 가격·설명·재고 표시
- 샷 추가(+500원), 시럽 추가(+0원) 옵션
- 옵션별 장바구니 항목 분리, 수량 조정·삭제, 가격 및 합계 계산
- 재고 범위 내 주문, 주문번호 생성, 주문 접수 저장 및 재고 차감
- 재고 0개 품절 표시 및 고객 구매 버튼 비활성화
- 관리자 주문 목록과 접수/제조 완료 상태 변경
- 관리자 재고 수정 및 전체 주문·주문 상태·품절 수량 요약
- 반응형 고객/관리자 화면과 공통 Footer

실제 결제, 관리자 로그인·권한 관리, 주문 취소, 서버 동기화 기능은 구현되어 있지 않습니다.

## 기술 스택

- HTML
- CSS
- Vanilla JavaScript
- 브라우저 `localStorage`

외부 프레임워크나 CSS 프레임워크는 사용하지 않습니다. 폰트는 Google Fonts를 연결하므로 네트워크 상태에 따라 해당 글꼴 사용 여부가 달라질 수 있습니다.

## 실행 방법

### 브라우저에서 직접 실행

1. 프로젝트 폴더에서 `index.html` 파일을 찾습니다.
2. 파일을 브라우저에서 엽니다.
3. 메뉴와 관리자 버튼으로 화면을 전환해 사용합니다.

### VS Code Live Server 사용

1. VS Code에서 프로젝트 폴더를 엽니다.
2. Live Server 확장 기능을 설치합니다(미설치된 경우).
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.

두 방법 모두 백엔드 서버 없이 정적 파일을 실행합니다. 저장 기능은 브라우저가 제공하는 `localStorage`에 의존합니다.

## 고객용 주문 화면 사용법

1. 메뉴 카드에서 음료 옵션을 선택합니다. 샷은 500원이 추가되고 시럽은 무료입니다.
2. 수량을 지정한 뒤 **담기 +** 버튼을 누릅니다. 옵션 조합이 다르면 장바구니에서 각각 별도 항목으로 표시됩니다.
3. 장바구니에서 수량을 변경하거나 항목을 삭제하고 합계를 확인합니다.
4. **주문하기**를 눌러 주문을 접수합니다. 주문이 정상 저장된 경우에 재고가 차감되고 주문번호가 표시됩니다.
5. 재고가 부족하거나 0개인 메뉴는 추가·주문할 수 없습니다.

## 관리자 대시보드 사용법

1. Header의 **관리자** 버튼을 눌러 관리자 화면으로 이동합니다.
2. 요약 카드에서 전체 주문, 접수, 제조 완료, 품절 메뉴 수를 확인합니다.
3. 주문의 **제조 완료** 버튼을 누르면 주문 상태가 저장됩니다. 상태 변경은 재고를 다시 차감하지 않습니다.
4. 재고 관리에서 메뉴 수량을 0 이상의 정수로 입력하고 **저장**을 누릅니다. 변경은 고객 화면에도 반영됩니다.

현재 관리자 화면에는 로그인이나 접근 권한 제한이 없습니다. 실제 운영 데이터 관리 용도로 사용하지 마세요.

## localStorage 저장 방식 및 주의사항

- 저장 키: `morrowCafeState`
- 저장 데이터: 메뉴 재고, 주문 내역과 상태, 장바구니
- 초기 데이터가 없을 때 기본 메뉴와 메뉴별 재고 10개를 생성합니다.
- 데이터는 현재 브라우저의 해당 출처(origin)에 저장됩니다. 브라우저/기기 간 자동 공유되지 않습니다.
- 사이트 데이터나 브라우저 저장 공간을 지우면 주문·재고 기록도 사라질 수 있습니다.
- 파일 직접 실행과 Live Server는 origin이 다를 수 있으므로 저장 데이터가 서로 다르게 보일 수 있습니다. 같은 주소/실행 방식으로 사용하세요.
- GitHub Pages로 배포해도 `localStorage` 데이터는 방문자의 브라우저에 저장되며, 저장소나 다른 사용자에게 공유되지 않습니다.
- 앱의 로컬 저장은 서버 백업, 인증, 다중 사용자 동시성 제어를 제공하지 않습니다.
